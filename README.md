# HTML & CSS Learning Path 

Welcome to my **HTML & CSS Learning Path** repository! This project documents my journey of learning the fundamentals of web development through practical examples, coding exercises, and hands-on practice.

The goal of this repository is to build a strong foundation in HTML and CSS and understand how modern web pages are structured, styled, and organized.

## What I'm Learning

### HTML Fundamentals
- HTML document structure
- HTML elements and attributes
- Headings, paragraphs, and text
- Images and basic page content
- Buttons and other common elements

### CSS Fundamentals
- CSS syntax and selectors
- Colors, fonts, and text styling
- Backgrounds and borders
- The CSS box model
- Display properties
- The `div` element and containers
- Nested layouts and layout techniques

### CSS Effects and Styling
- Hover effects
- CSS transitions
- Shadows and visual effects
- Website styling and presentation

## Technologies Used

- **HTML5** — Structuring web pages
- **CSS3** — Styling and designing web pages
- **Google Chrome DevTools** — Inspecting and debugging web pages

## Learning Goals

- Understand the fundamentals of HTML and CSS.
- Build and style simple web pages.
- Practice CSS layouts and visual effects.
- Learn to organize HTML and CSS code.
- Develop the foundation needed for more advanced frontend development.

This repository is a work in progress. I will continue adding examples, improving existing code, and exploring new web development concepts as I learn.
